# `survey/` — Kho paper tham khảo

Thư mục lưu file PDF các bài báo dùng cho phần related work và cho việc thiết kế phần
phòng thủ. Không có code, không được import bởi bất cứ đâu trong repo.

## Nhóm nội dung

| Nhóm | Ví dụ file |
|---|---|
| Tấn công đầu độc / backdoor agent | `agentpoisoning.pdf`, `Attractive Metadata Attack...pdf`, `Prompt_Infection_LLM_to_.pdf` |
| Tấn công vào hệ đa tác tử | `Red-Teaming LLM Multi-Agent Systems via Communication Attacks.pdf`, `CORBA.pdf`, `MAS.pdf`, `OMNI_LEAK_Orchestrator_Mu.pdf` |
| Phòng thủ / kiểm soát tool | `Think twice, Tool-Guard.pdf`, `A Survey of Adversarial Defenses and Robustness in NLP.pdf`, `TAMAS.pdf` |
| Red-teaming tự động | `AutoRedTeamer_Autonomous.pdf`, `openRT.pdf` |
| Survey nền tảng và an toàn | `survey_llm_safety_2305.11391v2.pdf`, `A Survey of LLM-Driven AI Agent Communication.pdf`, `international-ai-safety-report-2026_1.pdf` |
| Benchmark / giao thức | `A2ASecBench_A_Protocol_A.pdf`, `TAPAS_Datasets_for_LWE.pdf` |
| Kỹ năng đọc paper | `HowtoReadPaper (1).pdf` |

Thư mục con `seen/` chứa các paper đã đọc xong.

Quy ước đặt tên hiện tại chưa thống nhất (có file bắt đầu bằng ký tự lạ như `$`, `#`, `-`).
Khi thêm paper mới nên dùng dạng `<chủ đề>_<năm>_<tên ngắn>.pdf` để dễ tìm.
